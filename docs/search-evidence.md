# Saved search evidence (partial H05)

`POST /websites/{id}/search/dataset` accepts `site_url`, `start_date`, `end_date`, `dataset`, optional zero-based `offset` and `limit` (1–100). It authorizes the website and validates the property and dates, then reads `request_google_report`; it never requests Google or creates a collection job. Datasets are `queries`, `pages`, `query_pages`, `devices`, `countries`, `analysis`, and `landing_outcomes`. Rows come from the latest exact-period saved snapshot; daily canonical history alone cannot reconstruct these dimensions. `available: false` and `reason` distinguish absent snapshots or datasets from an empty observed result. `has_more` paginates retained rows, not Google's unreturned rows. `collection`, `measurement`, `sync`, and analysis policy/coverage are preserved when present. The semantics version is 1. Query rows exclude anonymized searches and Google does not guarantee a complete inventory. Landing outcomes use the site's GA4 binding, include all channels and are not attributed to search queries; sampled or thresholded results remain unavailable. Currency is unknown unless supplied by the provider.

Inspection history uses the existing owner-scoped `search_inspection_history` RPC, with its append-only cursor and owner-submitted provenance. An inspection concerns Google's indexed version and is not a live test.

Deploy the API before the web proxy/UI. No migration is required for this slice. Roll back web and API releases independently; neither changes stored observations. Existing dashboards and saved-data contracts remain available. There is no separate feature flag: defer the web release if the API route is unavailable. This is not full H05: selected device/country filtered query/page collection, crawl-finding correlation, live verification, and independent review remain outstanding. Snapshot pagination does not supply missing upstream observations or historical dimensions for arbitrary periods. Fixture tests do not establish production readiness.

Analysis candidates with array evidence return at most 25 evidence rows each, with `evidence_presentation` recording retained and returned counts and truncation. The full evidence remains in the saved source snapshot and the paginated `query_pages` dataset.
