# Independent audit imports and comparisons

HTP accepts S15 `controlled-csv-v1`: UTF-8 `url,rule,state`, where states are `present`, `absent`, or `unknown`. This is an explicit manual interchange, not a general vendor adapter. Exact URL and rule strings are matched; omitted observations remain unknown. The original UTF-8 source and SHA-256 are retained, along with user-supplied provenance. Record source tool/version, configuration, scope, rendering, parser, thresholds, fetch outcomes and rule definitions; missing metadata is unknown. Imported rows and source metadata must not be treated as authenticated claims by the producing tool. Keep independent evidence needed to reproduce them.

`s15-metadata-1` maps only `missing_title` and `missing_description`. All other rules are unmapped. A saved comparison pins the source import, SEOsmith receipt, semantics version and the user's assertion about the engine. The assertion is necessary but not sufficient: SEOsmith observations remain unknown unless the report is schema 1, unmodified engine 0.2.0 and ruleset 2026-11-01.1, complete and successful, and the particular page is eligible, successfully fetched and untruncated. A version string alone does not prove the unmodified engine. Other engines, unknowns, missing pages and incomplete evidence do not establish absence. Agreement is not ground truth. Known disagreements are categorized by which source observed the finding. Differences can reflect scope, rendering, parsing, fetches, thresholds or rule meaning; no proprietary aggregate score is equated. Comparisons are computed from the pinned sources; the source documents must be retained to reproduce them.

## Deployment and limitations

Apply `20261124000000_independent_audit_comparisons.sql` before deploying the standalone `/independent-audits` page or a dashboard link. The migration adds new tables and RPCs; existing audit reports and history contracts are unchanged. The functions enforce non-anonymous website ownership and hide prior-host evidence after a website rename. The website foreign keys restrict deletion while evidence exists; plan an explicit export and retention/deletion policy before any deletion. Original sources can be downloaded from the page.

This is not production verification. Before activation, test against actual S15 fixture outputs and authenticated end-to-end paths on an isolated site, including denied accounts, imports, replay, and rollback. History uses 100-item keyset pages. The receiver validates CSV grammar and duplicate observations; imports are limited to 4 MiB, 2,000 observations, and 8,192 bytes per encoded field. These bounds are narrower than the offline S15 harness. The browser page requires a verified unmodified controlled engine before comparison can produce known SEOsmith observations; normal production versions will usually remain unknown. No collection is initiated by reads.

Disable access/imports first during rollback. Export retained source and comparison records before using the destructive rollback SQL, which drops the new tables. No producer activation is required. The lifecycle dashboard link must ship after this page; coordinate with the lifecycle owner.
