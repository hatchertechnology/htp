# Disposable remediation normal-entry fixture

Run from the repository root after `cargo build --locked -p htp-api` and `npm ci && npm run build` in `apps/web`, with Node 22, Podman, and the lockfile-pinned Playwright Chromium installed. The digest-pinned PostgreSQL 17.11 and PostgREST v14.18 images specified in `run.sh` must be available locally (`--pull=never`). All temporary data, tokens and processes are created in this worktree and deleted on exit. Do not point this fixture at an existing database.

The isolated synthetic issuer signs ES256 user JWTs, verifies the Nuxt auth-user request, exposes its public JWKS, and transparently forwards REST traffic to actual PostgREST. SQL checks the held work-function ACLs before explicitly granting only the fixture's website-read, audit import/read and work functions to authenticated. It never mocks work RPCs. The actual API imports the checked-in schema 1 and 2 reports, then the built dashboard performs owner save, edit and attempt operations; API reads check the stored finding key and state, Nuxt routes reject an ordinary nonowner, and real attempts exercise keyset and browser pagination. Other dashboard modules are stubbed to avoid unrelated calls. This synthetic authentication and database fixture is not evidence of hosted grants or provider integration.
